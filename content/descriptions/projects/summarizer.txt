# 📰 Medium Summarizer — Intelligent, Privacy-First Blog Summarization Pipeline

An end-to-end automated content digestion pipeline that transforms the daily volume of Medium blog digests into concise, high-quality summaries using local AI—all while keeping your data offline, private, and secure.

## 🎯 Vision & Value Proposition
- **🔒 Privacy First**: Summarization runs entirely offline on local hardware—data never leaves your machine.
- **⚡ Zero Cloud Dependencies**: No API keys, no monthly SaaS subscriptions, zero vendor lock-in.
- **🤖 Local AI Inference**: Leverages Ollama running `deepseek-r1:8b-0528-qwen3-q4_K_M` for context-aware content compression.
- **🔄 Fully Automated**: Scheduled daily via Cron (7:30 AM)—fetches, scrapes via Freedium, summarizes, and delivers to your inbox.
- **📧 Daily Distilled Insights**: Preserves 100% of key technical concepts while eliminating ~70% of extraneous length.

---

## 🏗️ Architecture & Component Pipeline
1. **Master Orchestrator (`JUST-RUN-ME.py`)**: Manages the complete lifecycle, validates prerequisites, monitors Ollama service health, tracks execution times, and ensures graceful error recovery.
2. **Email Scraper (`medium_emails_scrapper.py`)**: Connects via IMAP to Gmail, extracts Medium Daily Digest links, filters deduplicated URLs, and cleans processed inbox emails.
3. **Paywall Content Extractor (`freedium_scrapper.py`)**: Uses Selenium and ChromeDriver to bypass Medium subscription gateways via Freedium, saving raw article structures.
4. **Intelligent Summarizer (`summarizer_ollama.py`)**: Executes local `deepseek-r1:8b` with dynamic prompt engineering tailored to narrative, technical tutorial, and listicle styles.
5. **Email Dispatcher & Auto-Cleanup (`send_me.py`)**: Concatenates formatted digests, transmits via Gmail SMTP, and automatically purges temporary files while preserving the lifetime deduplication tracker (`life_time_read_links.txt`).

---

## 🧠 Dynamic Prompt Engineering Highlights
- **Format Adaptation**: Automatically adapts prompt strategies based on whether the article is instructional, opinion-based, listicle, or technical narrative.
- **Non-Lossy Compression**: Enforces strict preservation of architectural steps, code logic, and core arguments.
- **Hallucination Prevention**: Rigid prompt constraints anchoring responses strictly to extracted DOM text.

---

## 🛠️ Technology Stack
- **Language**: Python 3.13.9
- **Local AI / LLM**: Ollama (`deepseek-r1:8b-0528-qwen3-q4_K_M`)
- **Web Scraping & Automation**: Selenium, ChromeDriver, BeautifulSoup4
- **Email Protocol Handling**: `imap-tools` (IMAP), `smtplib` (SMTP)
- **Scheduling & Utilities**: Cron (macOS/Linux), `tqdm`, `pathlib`, `requests`

## ⚙️ Quick Start & Local Setup
1. **Clone Repository**:
   ```bash
   git clone https://github.com/mr-mudgal/medium-summarizer.git
   cd medium-summarizer
   ```
2. **Environment & Dependencies**:
   ```bash
   python3.13 -m venv scrapper-venv
   source scrapper-venv/bin/activate
   pip install -r requirements.txt
   ```
3. **Pull Ollama Model**:
   ```bash
   ollama pull deepseek-r1:8b-0528-qwen3-q4_K_M
   ```
4. **Configure Credentials (`config.txt`)**:
   ```
   your-email@gmail.com|your-app-password|recipient-email@gmail.com
   ```
5. **Execute Pipeline**:
   ```bash
   python JUST-RUN-ME.py
   ```
6. **Automated Daily Cron (7:30 AM)**:
   ```cron
   30 7 * * * cd /path/to/medium-summarizer && /path/to/scrapper-venv/bin/python JUST-RUN-ME.py >> logs/execution.log 2>&1
   ```
