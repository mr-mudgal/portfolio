# Dual-GPU Multimodal Generative AI Publishing Pipeline

An automated, end-to-end publishing pipeline that leverages a local Qwen LLM art director, dual-GPU parallel SDXL ControlNet diffusion models, Potrace vectorization, and ReportLab canvas compilation to produce commercial-grade A4 print books (*Corporate Survival & Office Humor Coloring Book*).

---

## 🎯 Architectural Overview & 4-Phase Lifecycle

This system automates the complete print-on-demand publishing workflow, transitioning from creative prompt engineering to GPU hardware optimization and vector layout compilation.

```
┌─────────────────────────┐       ┌──────────────────────────┐       ┌─────────────────────────────┐
│  Phase 1: Local LLM     │ ────> │  Phase 2: Memory Flush   │ ────> │  Phase 3: Dual-GPU Vision   │
│  Qwen-2.5 1.5B Instruct │       │  (del, gc, empty_cache)  │       │  SDXL + ControlNet Canny    │
└─────────────────────────┘       └──────────────────────────┘       └─────────────────────────────┘
                                                                                    │
                                                                                    ▼
                                                                     ┌─────────────────────────────┐
                                                                     │  Phase 4: PDF Compilation   │
                                                                     │  ReportLab + Potrace Vector │
                                                                     └─────────────────────────────┘
```

---

## 🧠 Phase 1: Local LLM Prompt Engineering & Dynamic Themes
- **Model Architecture**: `Qwen/Qwen2.5-1.5B-Instruct` loaded with `transformers.pipeline` in `torch.float16`.
- **Dynamic Art Direction**: Ingests 30 curated corporate humor prompts (*The "Coffee & Exhaustion" Series*, *The "Meeting Survival" Series*, *The "Passive Aggressive" Series*, etc.).
- **Strict JSON Schema Directives**: Enforces structured outputs generating enhanced subject descriptions and two contrasting color schemes (*Flat Vibrant* and *Flat Pastel*) with solid cel-shaded anime rules, hex color palettes, and zero gradients.

---

## 🧹 Phase 2: VRAM Lifecycle & Memory Management
- **Explicit Garbage Collection**: Runs `del text_pipe`, `gc.collect()`, and `torch.cuda.empty_cache()` to completely free GPU VRAM before loading the heavy SDXL diffusion pipelines, preventing CUDA Out-Of-Memory (OOM) errors.

---

## 🚀 Phase 3: Dual-GPU Parallel Vision Pipeline (2x Speedup)
- **Model Stack**: `diffusers/controlnet-canny-sdxl-1.0` combined with `stabilityai/stable-diffusion-xl-base-1.0` using `EulerAncestralDiscreteScheduler` and attention slicing.
- **Hardware Parallelism**: Concurrently provisions `pipe_0` on `cuda:0` and `pipe_1` on `cuda:1` orchestrated via `concurrent.futures.ThreadPoolExecutor(max_workers=2)`, achieving a **2x generation speedup**.
- **Vector Conversion (`potrace`)**: Raw $1024\times1024$ line art is processed with OpenCV binary thresholding (`cv2.threshold`) and converted to resolution-independent SVG vector paths using `potrace`.
- **ControlNet Canny Colorization**: Generates 2 color guide thumbnails per page conditioned on Canny edge maps with a conditioning scale of $0.7$ for 100% boundary fidelity.

---

## 📚 Phase 4: Automated A4 Vector PDF Book Compilation
- **Vector PDF Layout Engine**: Built with `reportlab.pdfgen.canvas` and `svglib` (`svg2rlg`).
- **Commercial Print Standardization**: Automatically renders heavy 5px outer margins, bold page headers, scaled center vector drawings, and bottom dual color suggestion thumbnails with `#Hex` palette codes and "← Color Suggestions →" labels.
- **Target Deliverable**: `Corporate_Survival_Coloring_Book.pdf` ready for direct digital download or physical print distribution.
