## 💎 Portfolio Design System

This website is engineered from scratch with a distinct **iOS / VisionOS Liquid Glass aesthetic**:

- **Multi-Page Semantic Structure:** Dedicated pages for [Approach (index.html)](index.html), [Projects (projects.html)](projects.html), [Experience (experience.html)](experience.html), and [Education (education.html)](education.html).
- **Liquid Glassmorphism:** Layered `backdrop-filter: blur(40px) saturate(160%)`, frosted translucent borders (`rgba(255, 255, 255, 0.15)`), specular inner highlights, and ambient floating orbs.
- **Dual Theme Engine:** Dark Mode (`#080810`) and Light Mode (`#f5f6ff`) with smooth color-fade transitions and persistent `localStorage` theme toggling.
- **Dynamic Micro-Interactions:** 3D perspective card tilting (`[data-tilt]`), pointer cursor glow, and IntersectionObserver scroll reveal animations.
- **Zero Dependencies:** Pure HTML5, CSS3, and Vanilla JS. No build steps, no webpack, no node_modules required.

## 🌐 Deploying to GitHub Pages

To host this portfolio live on your GitHub profile:

1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "feat: complete portfolio refresh with liquid-glass design"
   git push origin main
   ```
2. Navigate to your repository **Settings** → **Pages**.
3. Under **Branch**, select `main` and root `/ (root)`.
4. Click **Save**. Your website will be live in seconds at `https://mr-mudgal.github.io/<repository-name>/`!
